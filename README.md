# Git Practice — Profile Card

A simple profile card for practicing Git commands.

## What to do

1. Edit `index.html` — replace the placeholder text with your own info
2. Edit `styles.css` — change colors, fonts, or layout to make it yours
3. Use Git to track and push your changes

This is a practice repo for learning: `git add`, `git commit`, `git push`, `git checkout -b`, and pull requests.
